# attic

Superseded working files, one line of reason each. Committed here rather than deleted: a
committed attic is a record, a deletion is a loss, and a gitignored file is a file that exists
on one machine only, which is the fault this repository exists to end. `git mv` keeps the
history, so `git log --follow` still reads back.

| File | Why it is here |
|---|---|
| `generate_skeleton_v0.py` | Superseded by `generate_skeleton_v1.py` on 17 July 2026, which reads the year spine from the project header instead of assuming it. v1 names v0 only in a docstring; no module imports it. Kept because it is the skeleton grammar the Plovdiv line set was first built against. |
